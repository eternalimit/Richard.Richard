# Deterministic Image Generation Control

## Purpose
Preserve the exact control path that produced a successful governed image-generation result.

## Deterministic Rule

INPUT
→ PRESERVE EXACT USER TERMS
→ RESOLVE PROJECT-DEFINED MEANING
→ REALITY CHECK
→ INFERENCE
→ INDEPENDENT ECHO
→ TCGE GATE
→ PASS OR HOLD
→ EXECUTE ONLY ON PASS
→ RECORD RESULT

## Required behavior

1. Capture the user's image instruction exactly.
2. Do not silently correct, normalize, reinterpret, or replace project-defined terms.
3. When a term may have a project-specific meaning, resolve that meaning from the authoritative project context before generation.
4. Reality (R) must identify the grounded request and available definition/evidence.
5. Inference (I) must state the exact visual interpretation that will be generated.
6. Echo (E) must independently validate the inference. Repetition by the same reasoning path is not Echo.
7. Compute:
   - K = R AND I AND E
   - H = I AND NOT K
8. Gate:
   - If R=1, I=1, E=1: PASS.
   - Otherwise: HOLD.
9. Image generation is permitted only after PASS.
10. On HOLD, do not invent the missing definition or validation.
11. Do not assign a human reprimand without evidence identifying a responsible human.
12. Record any control failure as a system/process violation unless evidence supports a different attribution.

## Deterministic image command

When the user says "Generate image" or gives an image request under this control:

REQUEST
→ TRACE
→ CHECK
→ GATE
→ ECHO
→ PASS
→ GENERATE

If Echo is missing:

REQUEST
→ TRACE
→ CHECK
→ GATE
→ HOLD
→ NO GENERATION

## Success condition

A run succeeds only when:
- the request is preserved,
- project terms are resolved without invention,
- R=1,
- I=1,
- E=1,
- K=1,
- the gate returns PASS,
- and the generated image matches the approved interpretation.

## Failure condition

Any generation that occurs before PASS is an uncontrolled generation event and must not be treated as an approved operating state.

## Canonical principle

Knowledge = Reality AND Inference AND Echo.

No inference becomes validated knowledge without independent Echo.
